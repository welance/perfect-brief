## Things worth not rediscovering

- **The live LLM judge is dead in production.** `POST /v1/score` with
  `judge=llm` returns 504 after ~15.15s on both prod and staging — an ingress
  read timeout, not Cloudflare (whose own is ~100s). The console hides it:
  `runLive()` catches, toasts "AI unavailable here", and leaves the **mock**
  number on screen with the mode selector still reading `live · LLM`. A visitor
  reads a keyword score believing it is an AI verdict. Fixing the timeout is
  platform config (tenants repo); making the fallback honest is a small change
  in `console.html` and has not been done.
- **Free AI is already ungated.** The server holds an OpenRouter key
  (`llm_configured: true`) and `judge=llm` needs no BYOK. Only
  `PB_DEFAULT_JUDGE=mock` and the broken ingress stand between a visitor and
  welance's credit — 60 req/min per IP, and `/v1/suggest/all` costs up to ~6 LLM
  calls per request. **Put a credit cap on the OpenRouter key, and land a quota,
  before the ingress is fixed.** Doing the timeout first goes from "broken" to
  "open bar".
- **`code.js` owns code blocks.** It only processes `.code` containers, token
  colours are scoped `.code .s` / `.code .kw`, and it rewrites the text of
  anything wearing `.code-copy` (so an "open →" link must use another class).
  Its guarantee — highlighting applied at runtime, copy yields clean source — is
  why the start chips use it instead of a second highlighter.
- **SVG text does not wrap.** The seam figure translates through the normal
  `data-i18n` path (`applyNodes` uses `textContent`, which works on SVG `<text>`),
  but every label has to stay short in all nine languages. On phones the figure
  keeps `min-width: 760px` and scrolls inside its band rather than shrinking to
  ~7px.
- **`.hl` is not a link style.** It marks the "change the rules" invitation, and
  a test asserts exactly one exists pointing at GOVERNANCE.md.
- **The gate is four rules**: `clear-title`, `problem-defined`, `budget-floor`
  (not_fail) and `anonymised` (pass). `timeline` is **not** one of them — a brief
  with no deadline loses points and still publishes. Any illustration showing a
  blocked brief must fail a gate rule; the canonical example is the `blocked`
  preset: 92/100, `Directory-ready`, blocked on `anonymised`.
