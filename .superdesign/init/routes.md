# Routes

- `/` → `site/index.html` — explanation and entry points
- `/calculators.html` → `site/calculators.html` — calculator index
- `/price.html` → `site/price.html` — Price Split calculator
- `/team.html` → `site/team.html` — Team Rate calculator
- `/console.html` → `site/console.html` — brief scoring console
- `/rules.html` → `site/rules.html`
- `/integrate.html` → `site/integrate.html`
- `/data.html` → `site/data.html`
- `/security.html` → `site/security.html`

All routes use `site/chrome.js`, `site/welance.css`, and language scripts.
The calculator routes additionally use `site/pricing.js`, `site/splitbar.js`,
and `site/mobile.js`.
